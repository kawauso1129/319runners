# リレー周回予測

時間制リレーで、たすき渡しをスマホでタッチ記録し、制限時間内の確定周回数を予測するWebアプリです。

## ファイル構成

```
index.html          … チーム画面（?team=合言葉 で開く）
admin/index.html    … 管理画面（Googleログイン）
js/config.js        … Firebaseの接続設定と調整値
js/core.js          … 予測計算・表示の共通処理
js/store.js         … データの読み書き（デモ／Firebase）
css/style.css       … 見た目
firestore.rules     … Firestoreのセキュリティルール
```

| 画面 | URL | 使う人 | できること |
| --- | --- | --- | --- |
| 管理画面 | `…/admin/` | 管理者 | 大会の作成・設定、スタート・リセット、チーム作成（合言葉とURL発行）、メンバー登録、全チームのCSV |
| チーム画面 | `…/?team=合言葉` | チームのメンバー | スタート、計測、差し替え、離脱、記録修正、予測、走順・ペースの微修正、大会後の照合、CSV |

## まず試す（デモモード）

`js/config.js` の `FIREBASE_CONFIG` が `null` のままだと、デモモードで動きます。データはそのブラウザの中だけに保存され、ログインも不要です。

ファイルを分けたため、ダブルクリックで開くと動きません。次のどちらかで開いてください。
- GitHub Pagesに置く
- フォルダで `python3 -m http.server` を実行し、`http://localhost:8000/` を開く

トップページから「管理画面を開く」「チームAで開く」を選べます。デモ大会は15分・1周0.2km（1周1分強）です。

## 本番の準備

### 1. Firebaseプロジェクトを作る（無料のSparkプランのまま）

1. [Firebaseコンソール](https://console.firebase.google.com/) でプロジェクトを作成する（Googleアナリティクスはオフで可）
2. 「構築 → Authentication → 始める」を開き、ログイン方法で **「匿名」と「Google」の2つ** を有効にする
3. 「Authentication → 設定 → 承認済みドメイン」に `ユーザー名.github.io` を追加する（管理画面のGoogleログインに必要）
4. 「構築 → Firestore Database → データベースを作成」を開く。ロケーションは `asia-northeast1`（東京）、本番環境モードを選ぶ
5. `firestore.rules` の `ADMIN_EMAIL@example.com` を、管理者のGoogleアカウントのメールアドレスに書き換える。Firestoreの「ルール」タブに貼り付けて公開する
6. 「プロジェクトの設定 → マイアプリ → ウェブ（</>）」でアプリを登録する。表示される `firebaseConfig` の中身を、`js/config.js` の `FIREBASE_CONFIG` に貼り付ける

```js
export const FIREBASE_CONFIG = {
  apiKey: "…",
  authDomain: "…",
  projectId: "…",
  storageBucket: "…",
  messagingSenderId: "…",
  appId: "…"
};
```

この設定値は公開されても問題ない種類の情報です。守りはセキュリティルール、管理者のGoogleログイン、チームの合言葉ワードで行います。

### 2. GitHub Pagesで公開する

1. GitHubにリポジトリを作り、上のファイル一式をフォルダ構成のままアップロードする
2. 「Settings → Pages」で、Branchを `main`、フォルダを `/ (root)` にして保存する
3. 数分後に `https://ユーザー名.github.io/リポジトリ名/` で公開される

### 3. 管理画面で大会とチームを登録する

1. `https://ユーザー名.github.io/リポジトリ名/admin/` を開き、Googleでログインする
2. 「新しい大会を作成」で、大会名・制限時間・1周距離を入れる
3. 「新しいチームを作成」で、チーム名と合言葉ワードを決める（ワードは自動生成も可能）
4. 各チームの「メンバー・チーム名を編集」で、名前・ペースを走順どおりに登録する
5. 「URLをコピー」で、チーム用URLを各チームのメンバーに配る

**合言葉ワードの決め方**
- 英数字とハイフンで12文字以上にする（自動生成を推奨）
- チーム名・大会名・日付・メンバー名は使わない
- 配布はメンバー内の連絡手段だけで行う

## 当日の使い方

1. 管理画面、またはどちらかのチーム画面で「スタート」を押す（全チーム共通）
2. たすき渡しの瞬間に、誰か1人が「タッチ（中継）」を押す。押した後30秒間は全端末でボタンが無効になる
3. 押し忘れた場合は、目安タイム＋30秒で自動的に暫定記録される。その後、次走者の目安の半分以内にタッチすれば、その時刻に訂正される
4. 走れない人がいる場合は「走者を差し替え」から今回走る人を選ぶ
5. 途中離脱は「メンバー」タブの「離脱」ボタンで行う
6. 終了後は「大会後」タブで暫定のまま残った周を修正し、CSVで保存する

**注意**：レース中は常に誰か1人以上がチーム画面を開いておいてください。自動の暫定記録は、開いている端末が行います。

## 調整できる値（js/config.js）

| 定数 | 初期値 | 意味 |
| --- | --- | --- |
| `LOCK_SEC` | 30 | タッチ後、全端末でボタンを無効にする秒数 |
| `GRACE_SEC` | 30 | 目安タイムを何秒過ぎたら暫定記録するか |
| `OUTLIER` | 1.5 | 目安の何倍を超える周に ⚠ を付けるか |
